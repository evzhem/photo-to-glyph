# Хорус 3 Pro: граница интеграции

Целевое устройство заказчика — робот-каллиграф «Хорус 3 Pro» семейства Kvenjoy. Плоттером управляет **KDraw**. PhotoGlyph только создаёт файл набора почерка; управление движением и оборудованием остаётся за программой плоттера.

Не подключаемся напрямую по Bluetooth/COM, не исследуем протокол устройства, не добавляем аппаратный драйвер.

Пользователь уточнил: наборы могут быть неполными, а подстановку отсутствующей буквы из другого набора выполняет **KDraw**, не PhotoGlyph. Экспортируем каждый набор отдельно; объединение наборов в приложении не требуется. Это сообщённый пользователем сценарий, не наша уже выполненная проверка конкретной версии KDraw. В M9 нужно проверить несколько наших неполных наборов и текст, покрываемый их объединением; настройка подстановки в интерфейсе программы пока неизвестна и не угадывается. См. `01-требования-mvp.md`.

## Установка набора

1. Экспортировать наш `.gfont` (этап M9; масштаб и некоторые поля ещё требуют проверки).
2. Скопировать файл в `<папка программы KDraw>/gcodefonts`.
3. Перезапустить KDraw.
4. Проверить появление набора в списке шрифтов.

Путь к каталогу установки зависит от компьютера пользователя и здесь не угадывается. Обязательность файла `.gfont.txt` пока не подтверждена.

## Порядок приёмки на устройстве

1. Зафиксировать версию KDraw, название собственного набора и настройки «Размера шрифта».
2. Проверить в превью буквы с петлями и хвостами: «Ж», «Б», «в», «Ш», «ф», «д», «р», «у», Ё/ё.
3. Запустить «Проверка недостающих слов» для выбранного приёмочного текста; отсутствующих символов быть не должно.
4. Подготовить устройство и лист по инструкции производителя; настройку пера и безопасность выполняет владелец.
5. Написать на бумаге «Привет, мир!» и контрольную строку с верхним/нижним регистром, цифрами и пунктуацией.
6. Проверить: осевые линии, не двойные обводки; отдельные штрихи не соединены рисующими перемещениями; хвосты ниже базовой линии; согласованные размер и интервалы.
7. Сохранить фото/видео и результаты вне Git с разрешения владельца. Записать подтверждённые единицы/масштаб и проблемы в отчёт M9.

В M0 есть только синтетический SVG-спайк. Он не подтверждает работу KDraw или устройства. При несовместимости `.gfont` предусматривается экспорт SVG/PNG, но не выдаётся за успешную аппаратную приёмку.
