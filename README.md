# PhotoGlyph

Android-приложение для русскоязычного пользователя: фотография рукописного алфавита → осевые штрихи → набор почерка для перьевого плоттера. Целевое устройство — «Хорус 3 Pro» (семейство Kvenjoy), управление — через KDraw.

Плоттер рисует **линии**, а не заливки. PhotoGlyph не обводит букву двойным контуром: конвейер строится вокруг скелетонизации. Ручной редактор штрихов входит в MVP, поскольку автоматика не всегда восстанавливает почерк правильно.

Алфавит: кириллица (включая Ё/ё), латиница, цифры и базовая пунктуация. Основной интерфейс — русский; код и коммиты — английские.

## Экспорт

Набор `.gfont` пользователь кладёт в `<папка KDraw>/gcodefonts`, затем перезапускает KDraw. Приложение **не** подключается к плоттеру по Bluetooth/COM. SVG/PNG предусмотрены как альтернативные экспорты.

Спецификация формата: [docs/04-формат-gfont.md](docs/04-формат-gfont.md). Единицы, кегль, служебные записи и необходимость `.gfont.txt` ещё не подтверждены реальным файлом.

## Структура

- `core/` — чистое Kotlin/JVM-ядро: обработка изображений и геометрия, без `android.*`.
- `app/` — Android, Jetpack Compose, CameraX, Room (с M1 и следующих этапов).
- `cli/` — JVM-прогон конвейера и диагностика.
- `tools/` — оригинальные синтетические фикстуры и генератор листа-сетки.
- `docs/` — спецификации и проверяемые отчёты.

## Проверки

M0 выполняется **до настройки Gradle**. В этом этапе будет добавлен самостоятельный скрипт `./tools/m0-check.sh`: он компилирует настоящее Kotlin-ядро, запускает тесты и конвейер на пяти PNG. Требуются JDK 17 и компилятор Kotlin/JVM; никаких нативных библиотек обработки изображений.

С M1 обязательная команда:

```sh
./gradlew build :core:test :cli:smoke
```

Её нельзя подменять заглушкой `gradlew`. В каждом отчёте приводится полный вывод реально выполненной команды и функции ядра, вызванные тестами.

## Приватность и лицензия

Обработка планируется локально. Не коммитить фотографии пользователей, чужие `.gfont`, ключи подписи и секреты. Допустимы только собственные небольшие синтетические тестовые фикстуры с указанным происхождением.
